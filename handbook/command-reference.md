# Command reference

The full command tables for the `cti-expert` skill, grouped by AEAD phase. `SKILL.md` §3 keeps the
entry point, the marker legend and a one-line index of every command; the detail lives here.

**Read the section for a command before you run it.** Each row says what backs the command:
**T2:** a CLI op (`scripts/backend/intel.py <op>`), **T1:** a typed MCP tool, **[model]** a way of
working with no code behind it, **[unimplemented]** documented tradecraft that nothing executes
yet. A row with none of these is treated as **[unimplemented]** (`SKILL.md` §3 legend).

Changed a collector's flags, a `DISPATCH` op or a `/command`? Update the row here and the index
line in `SKILL.md` §3 in the same commit.

The nine **registered** commands — `/cti`, `/cti-recall`, `/cti-case`, `/cti-pivot`, `/cti-cluster`,
`/cti-check`, `/cti-report`, `/cti-status`, `/cti-proxy` (one per `commands/*.md`) — are documented
with their T2 op and T1 tool in `SKILL.md` §3.0, not here; every other command below is a
loaded-skill convention.
